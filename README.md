# OptiBudget

PWA для инженерной оценки оптического бюджета PON-линий и каскадных топологий доступа.

## Возможности

- Профили GPON, EPON, 10G-EPON, XG-PON, XGS-PON и XPON с редактируемыми оптическими параметрами.
- Линейный калькулятор потерь волокна, PLC/FBT-сплиттеров, сварок и соединителей.
- **Каскадная топология**: OLT → магистральное волокно → PLC/FBT → абонентские ветки → несколько ONT/ONU. Каждый ONT получает отдельный расчёт пути, суммарных потерь, RX-мощности и запаса.
- **Редактируемый каталог оборудования** с производителем, моделью, технологией, TX/RX-параметрами, insertion loss, ссылкой на datasheet и датой проверки.
- Локальное сохранение журнала, топологии и каталога в браузере; экспорт расчётов и схем в JSON.
- PWA manifest и Service Worker для кэширования оболочки приложения.

## Запуск

Требуется Node.js 22 или совместимая актуальная версия.

```bash
npm install
npm run dev
```

## Проверка

```bash
npm test
npm run build
```

GitHub Actions workflow находится в `.github/workflows/ci.yml`.

## Инженерные ограничения

Стартовые профили и значения компонентов предназначены для демонстрации механики и редактируются пользователем. Они **не являются подтверждёнными паспортными характеристиками конкретных моделей**. До применения в проекте сверяйте TX, чувствительность и перегрузку приёмника, класс оптики, длину волны и insertion loss с официальными datasheet. Неподтверждённые параметры в каталоге оставлены пустыми намеренно.

Каскадная схема хранится локально в браузере; синхронизации между пользователями и серверного API пока нет.
