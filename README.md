# OptiBudget

Расчёт оптического бюджета GPON/EPON, каскадов PLC/FBT, карта трасс, журнал и облако (Supabase).

## UI

Стили платформы: **[@drycov/design-kit](https://github.com/drycov/design-kit)** (Telegram Dark/Light).

```bash
npm install
npm run dev
```

Подробнее: [docs/design-kit.md](docs/design-kit.md)

## Stack

- React + Vite + TypeScript
- Leaflet / react-leaflet
- Supabase (опционально)
- PWA
