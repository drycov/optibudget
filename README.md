# OptiBudget

PWA для инженерной оценки оптического бюджета PON-линий и каскадных топологий доступа.

## Возможности

- Профили GPON, EPON, 10G-EPON, XG-PON, XGS-PON и XPON с редактируемыми оптическими параметрами.
- Линейный калькулятор потерь волокна, PLC/FBT-сплиттеров, сварок и соединителей.
- **Каскадная топология**: OLT → магистральное волокно → PLC/FBT → абонентские ветки → несколько ONT/ONU. Каждый ONT получает отдельный расчёт пути, суммарных потерь, RX-мощности и запаса.
- **Каталог с происхождением данных**: опубликованные значения insertion loss для PLC-делителей Corning, ссылка на datasheet и шаблоны для OLT/ONT, волокна, сварок и соединителей. Шаблонные значения явно помечены и редактируются. В шаблоне GPON B+ приведены ориентиры TX/RX (не для приёмки конкретного устройства), а параметры PLC 1×4/1×8/1×16/1×32 и rack-mount 1×64 внесены из опубликованных спецификаций Corning.
- **Визуальная схема каскада** с автоматически расположенными узлами OLT, волокна, PLC/FBT, сварками, коннекторами и ONT/ONU; связи показывают родительские соединения, на узлах отображаются потери и результаты RX.
- Настройка длины волны по узлам и редактируемый класс оптики с расчётом остатка бюджета.
- Привязка OLT, ONT/ONU и PLC/FBT к каталогу с переносом подтверждённых RX и insertion-loss параметров; TX переносится только при заданном точном значении, не диапазоне.
- Отчёт по каждому ONT/ONU в CSV и печатная версия для сохранения в PDF через браузер.
- Локальное сохранение журнала, топологии и каталога в браузере; экспорт расчётов и схем в JSON.
- Устанавливаемое PWA: manifest, standalone display, иконка приложения, install CTA с системным prompt в поддерживаемых браузерах и инструкцией для iOS.
- Service Worker с версионируемым кэшем оболочки и собранных JS/CSS-ресурсов, офлайн-открытием интерфейса и обновлением кэша между релизами.
- Индикатор подключения: расчёты и сохранённый журнал доступны локально; установка и первая загрузка требуют HTTPS.

## Запуск

Требуется Node.js 22 или совместимая актуальная версия.

```bash
npm install
npm run dev
```

## Проверка

```bash
npm test
npm run build
```

GitHub Actions workflow находится в `.github/workflows/ci.yml`.

## Инженерные ограничения

Стартовые профили и значения компонентов предназначены для демонстрации механики и редактируются пользователем. Они **не являются подтверждёнными паспортными характеристиками конкретных моделей**. До применения в проекте сверяйте TX, чувствительность и перегрузку приёмника, класс оптики, длину волны и insertion loss с официальными datasheet. Неподтверждённые параметры в каталоге оставлены пустыми намеренно.

Каскадная схема хранится локально в браузере; синхронизации между пользователями и серверного API пока нет.
