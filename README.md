# OptiBudget

PWA для расчёта оптического бюджета линий доступа от OLT до ONT/ONU. Поддерживает профили GPON, EPON, 10G-EPON, XG-PON, XGS-PON и универсальный XPON, учёт PLC/FBT-сплиттеров, волокна, соединителей и сварок, а также локальный журнал расчётов.

## Запуск

```bash
npm install
npm run dev
```

Проверки:

```bash
npm test
npm run build
```

## Важно

Значения потерь и профили в MVP являются редактируемыми стартовыми параметрами, а не сертифицированными характеристиками оборудования. Перед проектированием сверяйте их с паспортами компонентов и требованиями оператора.
